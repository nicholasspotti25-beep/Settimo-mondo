# CREDITS

## Original work
Everything in this repository — code, procedural models, rigs and animation, shaders, visual effects, user interface art,
synthesized sound effects, generative music, world and story texts — was created for Settimo Mondo, in code.

No third-party art, audio, fonts or models are included. User-interface text uses the device's system font stacks.
